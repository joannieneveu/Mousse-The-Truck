# 📸 Family & Profile Photo Uploads

You can upload or replace images directly here in the `public/` folder in the **Code** tab:

1. **Family Photo**:
   - File name: `family.jpg` (or `family.png`)
   - Used for: The main hero banner on the *Our Family* page and travel overview.

2. **Joannie's Profile Picture**:
   - File name: `joannie.jpg` (or `joannie.png`)
   - Used for: Joannie's profile card, journal author avatars, and comments.

3. **Barton's Profile Picture**:
   - File name: `barton.jpg` (or `barton.png`)
   - Used for: Barton's profile card, driver profile, and comments.

4. **Henri's Profile Picture**:
   - File name: `henri.jpg` (or `henri.png`)
   - Used for: Little Henri's explorer profile avatar.

---
*Tip: Any file placed in `public/` is directly accessible via `/filename.jpg` across the entire application.*
